# 🪐 ÓRBITA - Diagnóstico de Competitividad

Aplicación para diagnosticar la competitividad empresarial basada en el Modelo ÓRBITA (Organización, Recursos, Bienestar, Innovación, Tecnología, Adaptabilidad).

## 🚀 Tecnologías

- **Frontend:** React + TypeScript + Vite
- **Estilos:** Tailwind CSS
- **Base de datos:** Supabase
- **Hosting:** Vercel

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/TU_USUARIO/orbita-app.git
cd orbita-app

# Instalar dependencias
npm install

# Copiar variables de entorno
cp .env.example .env.local

# Ejecutar en modo desarrollo
npm run dev
